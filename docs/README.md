# Canary requirements

Canary is a friendly, AI-assisted vulnerability notification and action-planning web application. These documents translate the WILDFIRE concept into implementation requirements.

## Documents

- [Product requirements](product-requirements.md): scope, users, outcomes, and product principles.
- [Functional requirements](functional-requirements.md): system behavior and end-to-end workflows.
- [AI and knowledge requirements](ai-knowledge-requirements.md): source ingestion, retrieval, explanations, and action-plan generation.
- [Security and privacy requirements](security-privacy-requirements.md): controls for a system handling sensitive incident and organizational data.
- [Data and technical requirements](data-technical-requirements.md): entities, integrations, availability, and operational behavior.
- [Acceptance criteria](acceptance-criteria.md): testable release criteria and a representative hospital breach scenario.

The first release should focus on trusted, relevant notifications and guided action plans. Broad regulatory coverage and automated remediation can follow after the core workflow is reliable.
